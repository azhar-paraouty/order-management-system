# Project Roadmap

## Purpose

This document tracks future ideas, enhancements and potential features.

Items listed here are not necessarily part of the current version.

---

# Main Version Scope

Focus Areas:

* Login System
* Product Management
* Order Creation
* Kitchen Queue
* Order Status Tracking

Technology:

* HTML
* CSS
* JavaScript
* PHP
* MySQL

Goal:

Create a functional full-stack restaurant order management system demonstrating the complete operational workflow.
